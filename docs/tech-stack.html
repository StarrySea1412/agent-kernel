一台敢碰生产的 Agent，由六个互相咬合的子系统组成。越往上越接近模型（会犯错），越往下越接近内核（不能犯错）。这张图不是框架清单，是责任划分：每一格问的都是「这里谁来兜底」。

LAYERSUBSYSTEMS ／ 每一格 = 一个必须存在的职责
L5策略层

模型调用

MODEL CALL

单次补全，带结构化输出约束。只允许在槽位内决策，不持有循环。

提示词装配

PROMPT ASSEMBLY

固定前缀 + 阶段化工具集 + 当前步骤；模板版本化，可回滚。

结构化输出

JSON SCHEMA

工具调用与结论都走 schema；解析失败按语义错误处理，不重试。

评审员

LLM JUDGE

窄任务裁判：判断「是否满足这几条断言」，不用来生成。

L4控制层

状态机

STATE MACHINE

阶段与迁移表由代码持有；模型无权决定进入哪个阶段。

CORE

预算墙

BUDGET

token / 步数 / 墙钟 / 调用数，四项共享；触顶即 halt，不商量。

停手条件

HALT RULES

重复指纹、无进展、连续验证失败、审批超时——五道闸。

拓扑编排

TOPOLOGY

Supervisor/Worker 或 Fan-out/Fan-in；子任务带 schema 与继承预算。

L3可靠性

前置守卫

GUARD

副作用发生之前拦：路径、schema、权限、预算、阶段白名单。

CHEAP

后置验证

ORACLE

语法 / 语义 / 事实三层；返回 verified / unverified / contradicted 三值。

补偿回滚

COMPENSATION

临时文件 + 原子重命名、事务、幂等键；不可撤销者必须人审。

失败分类

CLASSIFIER

瞬时 / 参数 / 语义，三种路由；语义失败绝不重试。

L2上下文

分级存储

L0–L3 MEMORY

工作集 / 便签 / 事实 KV / 事件日志；前三者是视图，日志是真相。

装配器

ASSEMBLER

定清单、排序、装填、记录丢弃；pin 段命中前缀缓存。

压缩策略

COMPACTION

只压过程不压事实；每三轮一次结构化摘要；事实进 KV。

检索

RETRIEVAL

按当前步骤取片段；切块与索引质量决定上限。

L1界面层

工具契约

TOOL SPEC

副作用等级、幂等性、超时、前置条件、错误分类、返回值裁剪。

返回值设计

TRIM

结论先行 + 证据指针 + next；日志进文件，不给全文。

权限白名单

SCOPE

子 Agent 物理上拿不到越权的工具；不靠提示词约束。

人类停点

HUMAN GATE

不可逆操作、审批超时、验证连败；超时走安全默认并留待办。

L0持久层

执行日记

JOURNAL

append-only，先写后做；输入哈希做幂等键。

快照与恢复

SNAPSHOT

每 N 步一份可恢复状态；进程被杀可续跑。

重放调试

REPLAY

不调模型，逐帧回看上下文装配与决策。

评测靶场

EVAL

终态 / 过程 / 基准三类断言；黄金轨迹回归内核。

WHY THIS SHAPE

上四层决定它有多聪明，下两层决定它有多可信。所有事故几乎都发生在「职责没有归属」的缝隙里——所以这张图的每一格都是一个问句：这里谁兜底？

内核约 2000 行，其中真正的「AI 代码」不到两成；其余是状态、预算、验证、日志。

THE ARITHMETIC

P(n steps) = pn
p=0.95, n=10 → 59.9%
p=0.95, n=20 → 35.8%
加守卫+验证：p' = 1−(1−p)(1−vr)
v=0.90, r=0.70 → p' = 98.2%
